Derivadas ao vivo

Releitura web de Derivadas de uma imagem (1969), de Waldemar Cordeiro e Giorgio Moscati.

A imagem vira uma grade de 98 x 112 pontos. Cada ponto recebe um número conforme o tom: 0 é claro, o maior número é escuro. O grau 1 é a diferença entre cada ponto e o vizinho. O grau 2 é a diferença aplicada sobre o grau 1. Clique numa linha de qualquer painel para ver os números.

O primeiro caractere é o tom 0 (claro). Os seguintes escurecem. Se houver menos caracteres que níveis, o último se repete.

A regra


  


  

    

      
Grau zero

      

      
A imagem quantizada.

    

    

      
Grau um

      

      
Diferença entre vizinhos. Revela os contornos.

    

    

      
Grau dois

      

      
A diferença aplicada ao grau um.

    

    

      
Tempo

      

      
Diferença entre este quadro e o anterior. Só o que se move aparece.

    

  


  

    
Leitura da linha

    
Clique numa linha de qualquer painel.
