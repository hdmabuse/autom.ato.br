Derivadas ao vivo

Releitura web de Derivadas de uma imagem (1969), de Waldemar Cordeiro e Giorgio Moscati. Relectura web de Derivadas de uma imagem (1969), de Waldemar Cordeiro y Giorgio Moscati. A web rereading of Derivadas de uma imagem (Derivatives of an Image, 1969), by Waldemar Cordeiro and Giorgio Moscati.

A imagem vira uma grade de 98 x 112 pontos. Cada ponto recebe um número conforme o tom: 0 é claro, o maior número é escuro. O grau 1 é a diferença entre cada ponto e o vizinho. O grau 2 é a diferença aplicada sobre o grau 1. Clique numa linha de qualquer painel para ver os números.

La imagen se vuelve una cuadrícula de 98 x 112 puntos. Cada punto recibe un número según el tono: 0 es claro, el número mayor es oscuro. El grado 1 es la diferencia entre cada punto y su vecino. El grado 2 es la diferencia aplicada sobre el grado 1. Haga clic en una línea de cualquier panel para ver los números.

The image becomes a grid of 98 x 112 points. Each point gets a number according to its tone: 0 is light, the highest number is dark. Degree 1 is the difference between each point and its neighbor. Degree 2 is the same difference applied to degree 1. Click a line in any panel to see the numbers.

O primeiro caractere é o tom 0 (claro). Os seguintes escurecem. Se houver menos caracteres que níveis, o último se repete. El primer carácter es el tono 0 (claro). Los siguientes oscurecen. Si hay menos caracteres que niveles, el último se repite. The first character is tone 0 (light). The next ones get darker. If there are fewer characters than levels, the last one repeats.
